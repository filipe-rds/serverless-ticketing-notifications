# Feature Development

**Version**: 1.0.0
**Type**: skills
**Authors**: aigile

## Overview

Implements feature tasks from an approved technical blueprint with the FRD as behavior reference.

## Usage

Point to the approved blueprint and FRD. The skill implements one or a few tasks at a time, announcing changes before making them and requiring approval at each stage. Follows `feature-blueprint`, feeds into `feature-review`.

## Dependencies

None

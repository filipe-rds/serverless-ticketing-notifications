# Docker Advisor

**Version**: 1.0.0
**Type**: skills
**Authors**: aigile

## Overview

Advises on Dockerfile, docker-compose, and container practices for security, performance, and dev/prod separation.

## Usage

Provide existing Docker configuration or describe the containerization needs. The skill reviews or creates Dockerfiles and compose configurations, applying best practices for multi-stage builds, security hardening, layer optimization, and environment separation.

None

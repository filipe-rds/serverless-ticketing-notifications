# Scaffolding Development

**Version**: 1.0.0
**Type**: skills
**Authors**: aigile

## Overview

Implements project scaffolding step-by-step from an approved blueprint.

## Usage

Provide the approved scaffolding blueprint. The skill implements each stage, running commands and verifying results, while the user reviews and authorizes progression. Follows `scaffolding-blueprint`, feeds into `scaffolding-review`.

## Dependencies

None

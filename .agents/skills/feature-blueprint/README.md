# Feature Blueprint

**Version**: 1.0.0
**Type**: skills
**Authors**: aigile

## Overview

Generates a detailed technical implementation blueprint from an FRD and architecture documents.

## Usage

Provide the FRD and relevant architecture docs. The skill produces a task-level blueprint at `docs/<feature>/blueprint-<feature>.md` for developer approval before implementation. Follows `feature-spec-brainstorm`, feeds into `feature-development`.

## Dependencies

None

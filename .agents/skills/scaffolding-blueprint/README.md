# Scaffolding Blueprint

**Version**: 1.0.0
**Type**: skills
**Authors**: aigile

## Overview

Creates an implementation blueprint from a scaffolding specification for developer approval.

## Usage

Provide the scaffolding specification. The skill produces a step-by-step blueprint including example entities and seed data. Follows `scaffolding-brainstorm`, feeds into `scaffolding-development`.

## Dependencies

None

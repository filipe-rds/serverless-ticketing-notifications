# Feature Review

**Version**: 1.0.0
**Type**: skills
**Authors**: aigile

## Overview

Reviews implemented feature code against the technical blueprint, FRD, and stack best practices.

## Usage

Provide the implemented feature code, blueprint, and FRD. The skill produces a severity-ranked review report at `docs/<feature>/review-<feature>.md` with findings and recommendations. Follows `feature-development`.

## Dependencies

None

# Scaffolding Brainstorm

**Version**: 1.0.0
**Type**: skills
**Authors**: aigile

## Overview

Iterative brainstorming to define initial project scaffolding, producing a scaffolding specification.

## Usage

Provide requirements and architecture documents for a new project. The skill guides iterative discussion on stack, structure, conventions, and boilerplate, outputting `docs/scaffolding-specification.md` and `AGENTS.md`. Feeds into `scaffolding-blueprint`.

## Dependencies

None

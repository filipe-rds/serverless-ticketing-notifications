# Feature Spec Brainstorm

**Version**: 1.0.0
**Type**: skills
**Authors**: aigile

## Overview

Iterative brainstorming to define feature scope and produce a Feature Requirements Document (FRD).

## Usage

Provide context about the feature you want to specify. The skill guides an iterative discussion to close scope, define requirements, and output a complete FRD at `docs/<feature>/frd-<feature>.md`. Feeds into `feature-blueprint`.

## Dependencies

None

# Feature Test Hardening

**Version**: 1.0.0
**Type**: skills
**Authors**: aigile

## Overview

Plans and implements comprehensive test suites for existing features, including seeds, test doubles, unit, integration, and E2E tests with coverage analysis.

## Usage

Point to an existing feature implementation and its specifications. The skill maps test scenarios, identifies coverage gaps, plans a full test suite for approval, then implements it. Produces a report at `docs/<feature>/test-report-<feature>.md`. Can follow `feature-development` or `feature-review`.

## Dependencies

None

# Synthetic Data Generation

**Version**: 1.0.0
**Type**: skills
**Authors**: aigile

## Overview

Generates realistic synthetic seed data in volume to populate databases for load and integration testing.

## Usage

Point to the project's data models/schemas. The skill reads entities and relationships, suggests appropriate faker libraries for the stack, plans seed generation for approval, then implements idempotent seeds with realistic data and proper relational consistency. Report at `docs/<feature>/synthetic-data-report.md`.

## Dependencies

None

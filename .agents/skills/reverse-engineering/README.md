# Reverse Engineering

**Version**: 1.0.0
**Type**: skills
**Authors**: aigile

## Overview

Derives a reverse FRD from source code and compares it to the original specification for gap analysis.

## Usage

Point to existing source code. The skill reads the code "blind" (ignoring specs), generates a reverse FRD, then compares it to the original specification to identify lacunas, excesses, and divergences. Produces a divergence report alongside the reverse FRD.

## Dependencies

None

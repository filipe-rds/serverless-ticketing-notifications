# Business Logic Hardening

**Version**: 1.0.0
**Type**: skills
**Authors**: aigile

## Overview

Hardens business logic against formal specifications: state machines, business rules, invariants, and contracts.

## Usage

Provide a formal specification (state diagram, transition table, business rules, invariants) alongside existing code. The skill maps gaps between spec and implementation, plans enforcement (guards, validators, state machines), and implements after approval. Strictly follows the spec — adds nothing beyond what is defined.

## Dependencies

None

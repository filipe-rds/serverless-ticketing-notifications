# E2E Flow Test

**Version**: 1.0.0
**Type**: skills
**Authors**: aigile

## Overview

Plans and executes end-to-end tests covering complete system flows from frontend to persistence.

## Usage

Provide the FRD, state diagrams, and existing code. The skill maps critical flows, plans E2E tests for approval, then implements them covering happy paths, error scenarios, and state transitions. Produces a report at `docs/<feature>/e2e-report-<feature>.md`.

## Dependencies

None
